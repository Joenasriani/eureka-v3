# Product language and surface rules

The interface must not borrow the visual or verbal grammar of common generative software.

Public copy should name operations that exist in the Eureka architecture, such as episode, residue, source field, crossing, representation, counter anchor, rival account, recognition, transfer, evidence, and boundary.

Rejected public patterns include generic AI slogans, chat bubble layouts, floating rounded panels, glass effects, decorative gradients, glow systems, ornamental neural diagrams, shadow based hierarchy, and generic dashboard decoration.

The public surface must not use en dash or em dash characters.

Changes to this rule require an explicit product decision, not incidental styling drift.
