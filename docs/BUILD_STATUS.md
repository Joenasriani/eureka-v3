# Eureka build status

## Running system

The application is a local web system with a server side reasoning pipeline and a browser interface derived from the Eureka case structure.

The current build contains:

1. User experience intake with exact anchors.
2. Experience graph construction.
3. AHA target routing.
4. Relational signature extraction.
5. Optional model based case interpretation constrained to admitted anchors.
6. P1 same case personal source search.
7. P1 prior case source search under explicit permission.
8. P2 explicitly familiar source search.
9. P3 remote source search.
10. P4 contrastive search.
11. G1 to G18 registry with selective routing.
12. Adaptive Bisociation Leveler.
13. Candidate collision and story replay.
14. Claim atomization.
15. Structural review.
16. Personal fit review.
17. Counter anchor and rival account review.
18. Optional independent model attack.
19. Optional live source claim inspection with web search.
20. Five separate status axes.
21. User recognition loop.
22. Material rerouting after known or failed candidates.
23. Self transfer recording.
24. Bounded real world transfer recording.
25. Retrieval profile updates that cannot modify truth status.
26. Stored case deletion and full ledger clearing.
27. Null outcomes for thin or unsupported cases.
28. Consequential case gate.
29. Influence autonomy boundary.
30. Public surface tests rejecting common generative interface patterns and wording.
31. Person Context storage with provenance and explicit permissions.
32. ChatGPT Person Context export prompt with access audit and structured JSON output.
33. Imported familiar fields feeding P2 and Leveler calibration.
34. Imported known concepts lowering obvious source priority.
35. Imported personal episodes eligible for P1 only when permitted.
36. Prior structured Eureka cases outranking broad imported history when both match.
37. Independent Person Context erasure.

## Runtime modes

Without model credentials, the tested local structural route remains usable.

With model credentials, the system can add open source matrix proposals, constrained case interpretation, independent adversarial review, and source claim inspection.

## Still outside this local build

Multi account authentication, encrypted hosted autobiographical storage, organization controls, and a large human scored AHA evaluation corpus require deployment infrastructure and data collection. They are not represented as complete in this package.
