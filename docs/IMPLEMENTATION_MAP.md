# Implementation map

| Requirement | Implementation |
| --- | --- |
| Experience graph | `server/parser.mjs` creates traceable anchors and episodes |
| Model case interpretation | `aiEnrichCase` may extend routing only through validated anchor references |
| AHA target | parser and optional model interpretation classify the unresolved target |
| Relational signature | target relations are formed before source retrieval |
| P1 same case source | admitted success episode can become the second matrix |
| P1 prior case source | earlier case can become P1 only when both cases permit history reuse |
| P2 source | familiar field requires explicit user supplied familiarity |
| P3 source | remote structure library plus optional open source proposal |
| P4 source | contrastive cases supply rival conditions and boundaries |
| G1 through G18 | generator registry with selective routing |
| Adaptive Leveler | source distance, abstraction preference, bridge tolerance, novelty floor |
| Structural review | local verifier plus optional independent model review |
| Personal fit | story replay must point to admitted current case anchors |
| Claim atomization | candidate claims and inferences are typed before arbitration |
| Source claim inspection | `/api/evidence` checks imported source mechanisms separately from personal fit |
| Counter anchor | candidate carries a strongest objection and boundary |
| Rival account | candidate carries a competing representation |
| Five axes | evidence, structure, personal fit, recognition, transfer are separate fields |
| User recognition | `/api/recognition` changes recognition and retrieval priors only |
| Material reroute | rejected or known source IDs are excluded from the next search |
| Self transfer | `/api/self-transfer` records user restatement and another suspected episode |
| Micro transfer | each candidate carries a bounded next test |
| Transfer outcome | `/api/transfer` records observed context only |
| Null outcome | thin input, high stakes, or failed candidate set can return no candidate |
| Learning | recognition and transfer alter retrieval priors without truth promotion |
| Case deletion | single case deletion and complete ledger clearing are available |
| Compiler rule | browser renders approved objects and creates no new claims |
| Public surface rules | automated tests reject specified common AI interface patterns and wording |
